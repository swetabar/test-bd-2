# table

Custom **table** block. Purpose: data table (e.g. credit ratings grid); typically placed in accordion panels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows -> table rows, cells -> table cells; first row is the header; a bold-only first cell becomes a row header; short rows span the last cell.
