# carousel-timeline

Custom **carousel** block. Purpose: company history timeline browsable by decade.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per milestone: picture | year heading (h3) + bullet list of events. Decades are not authored: the block groups rows by year to build the Select Decade dropdown (jump to the decade's first milestone) and draws the rail. 3 cards per view from 768px, 1 on mobile..

No variations.
