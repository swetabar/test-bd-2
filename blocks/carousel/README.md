# carousel

Custom **carousel** block. Purpose: horizontally scrolling card row (3-4 cards per view on desktop) with prev/next controls when cards overflow.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide: optional image/icon cell | content cell (heading, text, links).

## Behavior

White article cards (optional 220px image, optional eyebrow paragraph above the heading,
heading, text, arrow/external CTA). 3 cards per view from 768px, 1 below; prev/next arrows and
square dots appear only when cards overflow; each arrow click moves one page. Fewer cards than
slots are centred. Rows whose content starts with an eyebrow paragraph (newsroom stories) get the
wider 3-col card gutters automatically. Text-only cards use a cobalt title link.

No variations.
