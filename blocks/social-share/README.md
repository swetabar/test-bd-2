# social-share

Custom **embed** block. Purpose: row of share icons (Facebook, LinkedIn, email) for the current page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional list items or paragraphs naming networks (facebook, linkedin, x, email), optionally linked to override the share URL; empty block defaults to facebook, linkedin, email.

## Supported variations

No variations.
