# cards-icon

Custom **cards** block. Purpose: centered icon/pictogram feature cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: icon or image cell | body cell (heading, short text, optional link).

## Behavior

Renders as a slider that mirrors the source slick carousel: 3 cards per view from 1024px,
2 from 768px, 1 below. Prev/next arrows and square dots appear only when cards overflow;
each arrow click moves one page. Fewer cards than slots are centred.

## Supported variations

- `dark-grey` — charcoal heading (AIG Futura medium 23.4px) and description, as used for the
  internship cards on /home/careers/students-and-graduates. Default is navy (Futura medium 28px
  title, navy light description).
