# breadcrumbs

Custom **breadcrumbs** block. Purpose: page trail navigation (home icon, chevron separators, current page last).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell with a list of links, home first (e.g. :home: icon link); the last item is the current page as text or link. Empty block derives the trail from the URL.

## Supported variations

No variations.
