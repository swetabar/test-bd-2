# tabs

Custom **tabs** block. Purpose: horizontal wrapping tab list (e.g. regions) with one panel visible at a time.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: first cell = tab label, remaining cell(s) = panel content (text, link lists, sub-headings). The Cards option renders each panel as a grid of bordered cards (heading + text + link; 1/2/3 columns at mobile/768/993px): several content cells give one card per cell, a single cell is split at every heading of its first heading level (or at each horizontal rule).

| --- | --- |
