# downloads

Custom **cards** block. Purpose: downloadable materials list (document title + Download PDF link with size).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per document: title cell | download link cell (optional :download: icon). Grid option shows the items in two columns on wide screens. Narrow option centres the list in a two-thirds-width column (as on the corporate governance documents page) while the section heading stays full width.

## Supported variations

| Variation | Option class |
| --- | --- |
| Grid | `grid` |
| Narrow | `narrow` |
