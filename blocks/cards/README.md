# cards

Custom **cards** block. Purpose: generic card grid (image, heading, text, links).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: optional image cell | body cell (heading, text, links).

Layout: image on top on mobile; from 768px two cards per row with the image on the left (40%) and the body on the right. Standalone links in the body (e-mail, phone) stay plain underlined links, not arrow buttons.

No variations.
