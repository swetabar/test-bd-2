# accordion

Custom **accordion** block. Purpose: expandable FAQ/resource sections with +/- toggles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item: label cell (title) | body cell (rich text, links, lists). The Highlight option is a single prominent bar with an optional leading icon. The Cards option splits each body into a grid of bordered cards (1 column mobile, 2 from 768px): a new card starts at every heading of the body's first heading level (e.g. h3 card title, then label / contact lines / links), or at each horizontal rule.

## Supported variations

| Variation | Option class |
| --- | --- |
| Highlight | `highlight` |
| Cards | `cards` |
